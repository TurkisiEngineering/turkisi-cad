# Yeniden kurma

Gereksinim: Python 3 + build123d 0.11.1 (OCP dahil).

```
cd teslim
python miter_gear.py
```

Betik `miter_gear.py` ile aynı klasöre `final.step` (AP214, mm, spec çerçevesi) yazar ve
geçerlilik / hacim / alan / ağırlık merkezi / sınır kutusu / yüz sayısını ekrana basar.
Başka girdi dosyası gerekmez; tüm ölçüler betiğin başındaki parametrelerde.
