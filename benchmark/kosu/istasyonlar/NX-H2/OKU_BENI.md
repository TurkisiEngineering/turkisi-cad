# NX-H2 istasyonu

Yayındaki beşinci istasyon Siemens NX 2206 + Usta'nın kendi NX harness'i (H2: NX MCP + uzman skill'ler + journal
yardımcıları) ile çalıştı. Bu harness özeldir, paylaşılmıyor: istem, kuyruk, skill ve NX çıktıları bu repoda yok.
NX-H2 koşularının puanları yayında gösterildiği için `benchmark/sonuclar/puanlar.csv`'de duruyor.
